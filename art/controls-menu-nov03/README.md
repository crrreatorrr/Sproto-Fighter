Prompt pattern (crests; the sapphire version swaps the gem):

> Pixel art game UI emblem, isolated on a fully transparent background. A small
> heraldic crest badge in the exact style of the reference images: dark iron
> body, ornate antique gold filigree border, tiny teal rivets, crisp pixel
> edges, no anti-aliased blur. At its centre one large faceted ruby gem glowing
> deep crimson red. Symmetrical, front-facing, centred, fills most of the
> canvas. No text, no letters, no numbers, no background, no shadow on the ground.

Icons used the same style language: four blank WASD-arrangement keycaps with
gold rims and amethyst corners; a two-handed controller in dark iron and gold
with amethyst face buttons. Both forbade text and background.
