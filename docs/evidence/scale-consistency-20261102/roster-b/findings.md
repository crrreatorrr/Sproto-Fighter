# Roster B size/framing visual sample review

Coverage: roster indices 65–129 inclusive, 65 selectable owners, 77 bodies (both bodies of 12 paired owners), 1,232 representative cells. All 26 pages were opened with the image-view tool.

Manifest snapshot: `danocrypto-8662eebcaf9b3335-solana870549bd5e` / `f30be61751cc73cbfe579ef0a569a2fc9cd87a04d50b5a2f8662ecb1d01ed11c`.

Every sheet uses the actual atlas scale and per-frame foot anchor, then one uniform 0.85 display scale. Root and floor lines are fixed; no per-image bounding-box fitting. Expanded detail sheets use actual atlas scale at uniform 1.0 view.

This is static pixel sampling, not full-motion, camera, timing, paired spacing or gameplay acceptance. Findings below describe the captured originals. All eight confirmed bodies now have corrections accepted in the independent static repair review; implementation is owned elsewhere.

## Repair review

All seven motion sets and the sproto2789 walk remap are accepted for static size/framing. Reviewed 224 corrected motion assets in both facings (448 cel views), plus all four remapped walk cels in both facings. The current manifest entries match the reviewed files. See [independent repair review](repair-review.md) for factors, measured head/eye landmarks, hashes and limits. Browser motion acceptance is separate.

## Confirmed findings

- **sproto2789 — high:** Dedicated walk cels are smaller than canonical core poses. Frames4–7 include staff thrust, overhead/downward swing and hop instead of stride. Core poses02–05 are coherent authored stride alternatives. Sequences: walk[0..7]. Evidence: [sproto2789-walk-detail.png](sproto2789-walk-detail.png).
- **sproto3224 — medium:** Every inspected jump/heavy motion cel enlarges head/body versus canonical core and walk, approximately 24% in the head; raised-arm/crouch attitude does not explain this. Sequences: jump[0..5], heavy[0..7]. Evidence: [sproto3224-motion-detail.png](sproto3224-motion-detail.png).
- **sproto3224-companion — medium:** Every inspected jump/heavy cel is moderately larger than the corresponding canonical body. Glasses width/height increase provides a stable facial landmark. Sequences: jump[0..5], heavy[0..7]. Evidence: [sproto3224-companion-motion-detail.png](sproto3224-companion-motion-detail.png).
- **sproto3235 — high:** All 14 jump/heavy cels noticeably enlarge head, torso and limbs. Isolated blue head width grows 45%; opaque head area approximately doubles. Sequences: jump[0..5], heavy[0..7]. Evidence: [sproto3235-motion-detail.png](sproto3235-motion-detail.png).
- **sproto3235-companion — medium:** All 14 jump/heavy cels enlarge the head/body approximately 20–25% visually against coherent canonical core poses. Blue components join anatomy, so component area is not a clean head metric. Sequences: jump[0..5], heavy[0..7]. Evidence: [sproto3235-companion-motion-detail.png](sproto3235-companion-motion-detail.png).
- **gryph-companion — medium:** Full jump/heavy sequences enlarge the companion; head width increases 29–31% versus core. Sequences: jump[0..5], heavy[0..7]. Evidence: [gryph-companion-motion-detail.png](gryph-companion-motion-detail.png).
- **godmod3d — medium:** Full jump/heavy sequences enlarge primary body/head. Blue head width increases 26–32%; heart/hat changes alone cannot explain this. Sequences: jump[0..5], heavy[0..7]. Evidence: [godmod3d-motion-detail.png](godmod3d-motion-detail.png).
- **nosmileclown — medium:** Full jump/heavy sequences have a milder persistent enlargement: blue head width 19–22% larger and area 43–48% larger than core. Sequences: jump[0..5], heavy[0..7]. Evidence: [nosmileclown-motion-detail.png](nosmileclown-motion-detail.png).
