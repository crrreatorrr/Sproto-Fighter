# Independent correction review

Accepted the seven listed body candidates after viewing their fixed-scale source-cel sheets. This is a separate review of 151 corrected cels in both facings (302 corrected-cel displays), plus the before/core comparison sheets. These totals are not included in the 1,152 original roster samples. This review does not verify continuous motion, animation transition timing, camera behavior, or runtime installation.
